# MEET-HOMIE

MEET-HOMIE is an intuitive, lightweight scheduling application designed to facilitate one-on-one meetings by matching user preferences. The app eliminates the need for lengthy email exchanges and account registrations, offering a user-friendly solution for efficient meeting scheduling.

## Problem Statement

Scheduling meetings often involves a cumbersome exchange of emails or messages to find a mutually convenient time, wasting valuable time and delaying important decisions. Existing scheduling tools usually require both participants to register and manage accounts, which can deter some users.

MEET-HOMIE addresses these issues by offering a streamlined scheduling experience. The app allows organizers to propose multiple time slots, and invitees can select their preferences without the need for an account, enabling quicker and more efficient scheduling.

## Main Features

- **One-On-One Meeting Scheduling**: Schedule meetings between two parties with a streamlined booking and confirmation process.
  
- **Preference-Based Scheduling**: Hosts can prioritize their available times as high, medium, or low preference, guiding the scheduling process.

- **Schedule Matching**: The system analyzes preferences from both the host and invitee to suggest the best possible meeting time, optimizing for mutual convenience.

- **Comprehensive Dashboard**: Both hosts and invitees can view and manage their scheduled meetings on a user-friendly dashboard, enhancing user experience and accessibility.

- **Editable User Profiles and Contact Lists**: Users can update their profile information and manage their contacts, ensuring ease of use and personalization.

## Tech Stack

- **Frontend**: React.js, Tailwind CSS, Material UI
- **Backend**: Node.js, Django, SQLite
- **API Testing**: Postman

## Installation Guide

### Setup Backend

1. Navigate to the backend directory:
  ```bash
  cd backend
  ```
2. Run the setup script:

  ```bash
  ./startup.sh
  ```
3. Start the backend server:
  ```bash
  ./run.sh
  ```
### Setup Frontend

1. Navigate to the frontend directory:
  ```bash
  cd frontend
  ```
2. Install the necessary dependencies:
  ```bash
  npm install
  ```
3. Start the frontend server:
  ```bash
  npm start
  ```
